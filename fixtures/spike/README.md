# M0 spike fixtures

Source snippets for 30 molecules, used to compare models in the M0 spike. Generated by `scripts/fetch_spike_fixtures.py` (October 2026); rerun it to refresh.

Each file holds `molecule`, `cid` and a list of `snippets` with `id`, `source` (`pubchem_view` or `wikipedia`), `section`, `url`, `origin` (the original data provider) and `text`.

Coverage:
- **PubChem PUG-View:** Record Description, Uses, Natural Pollution Sources, Toxicity Summary, GHS Classification (first authority listed).
- **Wikipedia:** the introduction, History, and up to 2 paragraphs from other sections. Boilerplate and sections on making or extracting the substance are skipped.
- **Mix of cases:** the set includes well-documented molecules (caffeine, morphine) and sparse ones (cubane, geosmin), plus molecules with no GHS data (cubane, batrachotoxin).
